3. Jelaskan apa yang dimaksud dengan perintah git : init, clone, remote, add, commit, push dan checkout
    jawaban : 1. git init : Digunakan untuk membuat repository yang ada pada file lokal dan berlokasi di folder git.
              2. git clone : Digunakan untuk mengkloning repository dari server git ke direktori lokal.
              3. git remote : Digunakan untuk mengatur alamat server git yang akan digunakan memungkinkan untuk berkolaborasi.
              4. git add : Digunakan untuk perintah menambahkan file baru ke repository yang baru dipilih. 
              5. git commit : Digunakan untuk menyimpan perubahan versi revisi pada repository git.
              6. git push : Digunakan untuk mentransfer perubahan file ke repository remote setelah melakukan perubahan. 
              7. git checkout : Digunakan untuk mengganti branch yang sedang digunakan.

5. Apa bedanya variable user dengan variable system ?
    jawaban : Variabel user adalah variabel yang kita buat dan tetapkan dalam daftar perintah.
              Variabel sistem adalah pengaturan konfigurasi yang dapat diubah oleh pengguna.
              Perbedaan antara variable user dan variable system terletak pada, siapa yang dapat mengaksesnya, dan bagaimana mereka digunakan.
              1. Variabel user 
                 - Variabel user hanya berlaku untuk user account tertentu
                 - Variabel ini disimpan secara spesifik dalam lingkungan pengguna tersebut.
                 - Contoh : C:\Users\NamaPengguna\Documents
              2. Variable System
                 - Variabel system berlaku untuk semua pengguna di sistem operasi
                 - Variabel ini disimpan dalam konfigurasi sistem dan diterapkan secara global.
                 - Contoh : C:\Windows\System32
